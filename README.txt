# Saurav Ravindra Upadhyay - Portfolio

## Files

- `index.html` — website structure/content
- `style.css` — design, layout and responsive styling
- `script.js` — interactive/dynamic features
- `profile.jpg` — your uploaded profile photo

## How to run

1. Keep all four files in the same folder.
2. Double-click `index.html`.
3. It will open in your browser.

For VS Code, you can also install the Live Server extension and open `index.html` with Live Server.

## What the JavaScript does

1. Opens/closes the mobile navigation menu.
2. Creates the typing animation in the hero section.
3. Automatically updates the copyright year.
4. Shows a success message when the demo contact form is submitted.
5. Adds smooth back-to-top behavior.
6. Reveals cards/sections as they enter the screen.
7. Highlights the navigation item for the section currently being viewed.

## Important note about the contact form

The contact form is currently a front-end demo. It does not send emails to you.

If you want real messages, connect the form to a backend/API or a form service later. Your Phone, LinkedIn and Instagram contact cards already work as links.

## How to customize

### Change your introduction
Open `index.html` and edit the text inside the hero and About sections.

### Add your real projects
Inside the `projects-grid`, replace the three example project cards with your own projects.

### Skills included
The Skills section includes HTML, CSS, JavaScript, React.js and Next.js.

To add more skills, copy one `.skill-card` in `index.html` and change its title and description.

### Change colors
Open `style.css` and edit the variables at the top, especially:
- `--accent`
- `--accent-2`
- `--bg`
- `--bg-soft`

### Change the profile photo
Replace `profile.jpg` with another image, keeping the same filename.

## Social links included

LinkedIn and Instagram are already connected in both the hero and Contact sections.
